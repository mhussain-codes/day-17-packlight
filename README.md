# Packlight — Day 17

Packlight builds a practical packing checklist for a trip. Choose the number of days, likely weather, travel style, and a couple of useful extras. Edit the suggestions, check items off, and print or export your list.

**Live demo:** https://mhussain-codes.github.io/day-17-packlight/

## Features

- Generate a starter checklist based on trip length, weather, and travel style.
- Add child travel and laundry extras.
- Add custom items, remove suggestions, and check packed items off.
- See packing progress at a glance.
- Print the checklist or export a CSV copy.
- Saves the current list in this browser on this device; no account, server, or third-party libraries.

## How to use

1. Open the [live demo](https://mhussain-codes.github.io/day-17-packlight/).
2. Set trip name, length, weather, and travel style.
3. Select **Build my checklist**.
4. Edit the suggestions, add your own items, and mark packed items.
5. Print the checklist or export a CSV file to take it with you.

The suggestions are a starting point, not travel or destination-specific advice. Check your route, airline baggage rules, weather forecast, and any document or medication needs before you leave.

## Privacy

The trip name and checklist stay in local storage in this browser on this device. They are not sent to a server. Clearing browser site data removes the saved list.

## Run locally

Open index.html in a modern browser. It has no build step or third-party dependencies.
